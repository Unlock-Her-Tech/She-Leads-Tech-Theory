# 📘 Theory Session 02 — Palindromes

> Explore two different palindrome problems using frequency counting, sets and expanding pointers.

[Theory home](../../README.md) → **Session 02**

## Learning goals

By the end of this session, you should be able to:

- Distinguish constructing a palindrome from finding a palindromic substring
- Use paired character counts to build the longest possible palindrome
- Expand around a centre using two pointers
- Compare approaches using time and space complexity

## Suggested order

1. Start with Longest Palindrome and reuse frequency-counting ideas from Session 01.
2. Compare the set-based and pointer-based solutions.
3. Move to Longest Palindromic Substring and clarify how its output differs.
4. Trace odd- and even-length centres by hand.
5. Compare the complexity of the discussed approaches.
