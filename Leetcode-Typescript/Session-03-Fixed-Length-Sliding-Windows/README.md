## Suggested order

1. Describe the brute-force calculation.
2. Identify the work repeated between adjacent subarrays.
3. Build the first window sum.
4. Move the window by adding the incoming value and removing the outgoing value.
5. Compare the live brute-force and sliding-window solutions.
