# Maximum Subarray Sum

You are given an array of length `n` (containing the number of API requests a client has attempted to make over each of the last `n` minutes), an integer `k` (representing a window size in minutes) and a fixed rate limit per client for every `k`-minute window.

Work out whether the client's API usage has exceeded the rate limit at any point, and if yes, by how much during the `k`-minute window of heaviest usage.
